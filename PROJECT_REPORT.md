# Итоговая работа по дисциплине «Программная инженерия»

**Тема: разработка и контейнеризация веб-сервисов на FastAPI**

## 1. Выполненная работа

В рамках итогового задания разработаны два самостоятельных веб-сервиса на Python с использованием FastAPI:

- ToDo Service — сервис управления списком задач.
- Short URL Service — сервис сокращения ссылок.

Для хранения данных используется SQLite. Для каждого сервиса подготовлен отдельный Dockerfile.

## 2. Реализованный функционал

**ToDo Service:**

- создание задачи;
- получение списка задач;
- получение задачи по идентификатору;
- редактирование задачи;
- удаление задачи.

**Short URL Service:**

- создание короткой ссылки;
- перенаправление на исходный URL;
- получение информации о ссылке по идентификатору.

Для обоих сервисов предусмотрена автоматическая документация API посредством Swagger UI.

## 3. Контейнеризация

Выполнена сборка Docker-образов и запуск контейнеров.

Для обеспечения сохранности данных используются именованные Docker Volumes:

- `todo_data`;
- `shorturl_data`.

ToDo Service работает на порту 8000, Short URL Service — на порту 8001.

## 4. Тестирование

Проведено тестирование приложений, проверена работоспособность основных методов API и перенаправления по короткой ссылке.

Выполнен перезапуск Docker-контейнеров. Подтверждено сохранение данных после перезапуска.
